# jiwari（じわり書き）

淡墨で和紙に書くWebアプリ。なぞると細い線がにじみ、筆を止めると墨がじわりと広がる。スマホでもPCでも動き、ブラウザの中だけで完結する。

https://www.somikubota.jp/jiwari/

## 書き方
- 指（PCはマウスのドラッグ、タブレットはペン）でなぞると、淡墨の細い線がにじむ。ゆっくりだと太く、速いと細く淡く
- なぞる途中で止めると、筆先から墨が染み出して溜まり、じわりと広がる。書き始めも同じ
- 色は淡墨・藍・朱。重ねると濃くなる
- 「水の量」（1〜10、初期値7）を上げるほど、にじみが広く柔らかくなる
- 「新しい紙」で紙を替え、「保存」でPNGを保存

## しくみ
- 画面を細かいマス目に分け、マスごとに水・流れている墨・紙に定着した墨の量を持つ
- 水は量の差に応じて隣のマスへ流れ、墨は水に運ばれる。紙には吸い込みやすさのむらがあり、乾いたところへは入りにくいので、縁がほどよく不揃いになる
- 水が少なくなったところから墨が紙に定着するので、乾くと縁が少し濃く残る
- `?nodemo` を付けると最初のお手本の三画を出さない
