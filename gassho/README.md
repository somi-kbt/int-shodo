# gassho（合書）

はなれたふたりが、それぞれのスマホやPCのカメラの前で同時に書いて、同時に鳴らす、ポップな書道アプリ。空書（kuusho）の筆をもとにしている。

https://www.somikubota.jp/gassho/ ・ https://gassho-shodo.vercel.app

## あそび方
- 自分の色（ピンク・ソーダ・レモン・ライム・オレンジ・パープル）を選ぶ
- 一人が「部屋をつくる」で4桁の部屋番号を作り、招待リンクを送る。もう一人はリンクを開くか、番号を入れて「部屋に入る」
- どちらかが「書きはじめる！」を押すと、二人同時に 3・2・1・GO! で15秒間書ける
- 5本の指先がふちになるまるい筆。ひらくと太く、すぼめると細く、グーでストップ
- 終わると、二人の線がつやのあるチューブになった3Dと「シンクロ率」が出る

## 音と演出
- 手を動かすと音が鳴る。自分はマリンバ、相手はシンセ。同じペンタトニック音階なので必ずハモる。高さで音程、太い筆は1オクターブ下
- 書いている間はビート（116 BPM）が鳴る
- 速く払うとシュッという音と、マンガの効果線のようなスピード線・星が飛ぶ。スピード線は作品にもうっすら残る
- 筆を下ろすとポン、グーにするとポン↓。二人の筆が近づくとキラキラ音と星が弾ける
- iPhoneのマナーモードでも鳴るようにしている。「🔊 音テスト」で確認できる

## 通信
PeerJS（WebRTC）で端末同士を直接つなぐ。送るのは筆の位置・太さ・色だけで、映像は送らない。携帯回線どうしだとつながらないことがあるので、その場合は二人とも同じWi-Fiにつなぐ。

## 3Dプリント（2色）
3D画面の「🧊 3Dプリント用（2色）」で 3MF ファイルを保存できる。自分の線と相手の線が、ひとつの作品の中の別パーツ（「自分」「相手」）になっているので、Bambu Studio や PrusaSlicer などで開いて、パーツごとにフィラメントの色を割り当てれば2色で印刷できる。大きさは長い辺が100mm、細すぎる線は半径0.9mmまで太くしている。「台座」をオンにすると（初期設定）、厚さ3mmの板と、各線を支える柱が3つ目のパーツ「台座」として入るので、全体がひとつながりで印刷できる。

## PCで使う
- PCのWebカメラでもあそべる。スマホとPCの組み合わせでもつながる
- カメラが1台しかないときは切替ボタンを隠す
- スペースキーかEnterキーでも書きはじめられる
