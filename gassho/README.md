# gassho（合書）

離れたふたりが、それぞれのスマホのカメラの前で同時に書く書道アプリ。ふたりの線が両方の画面にリアルタイムで現れ、アンビエントな音になって重なる。空書（kuusho）の筆をもとにしている。

## 書き方
- 一人が「部屋をつくる」で4桁の部屋番号を作り、招待リンクを送る。もう一人はリンクを開くか、番号を入れて「部屋に入る」
- どちらかが「書き始める」を押すと、二人同時にカウントダウンが始まり、15秒間書ける
- 5本の指先がふちになる丸い筆。指を広げると太く、すぼめると細く、グーで筆が上がる
- 速く払うとかすれ、ゆっくり留めるとにじむ
- 終わると、二人の線が重なった3Dになる

## 音
書いている線がアンビエントな音になる。高さで音程（共通のペンタトニック音階なので二人の音がハモる。相手は1オクターブ上）、太さで音量、左右で定位、速さで明るさが変わり、かすれでは息のような音が混ざる。音程が変わるとガラスのような鈴が鳴り、下では低いドローンが鳴り続け、全体に長い残響がかかる。

## 通信
PeerJS（WebRTC）でスマホ同士を直接つなぐ。送るのは筆の位置・太さ・色だけで、映像は送らない。携帯回線どうしだとつながらないことがあるので、その場合は二人とも同じWi-Fiにつなぐ。
