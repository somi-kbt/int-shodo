# chirashi（散らし）

短歌を入力すると、ひらがなを万葉がな（字母）に置き換えて、色紙・短冊・半紙に散らし書きで並べるWebアプリ。漢字はそのまま残す。AIは使わず、ブラウザの中だけで動く。

## できること
- 「変体仮名」：ひらがなの一部を、Unicodeに登録された変体仮名（崩した仮名）に置き換える。字体は Noto Serif Hentaigana（SIL Open Font License）。どの変体仮名がどの漢字から来たかは Unicode の文字表による
- 「万葉がな」：ひらがな（カタカナ・濁音・小書きも）を万葉がなの漢字に置き換える。同じ音が続くときは字母を変えて変化をつける（「基本の字母」にすると常に同じ字）
- できあがった字をタップすると、別の字母に切り替わる
- 料紙（色紙・短冊・半紙）と構成（流れ・返し・三行など）を選べる
- 字形を縦長・横長・台形・菱形・傾きに変形して、散らし書きらしい表情をつける（そのまま／控えめ／大胆）
- 連綿（なし／少し／多め）：前の字の書き終わりと次の字の書き始めを字の形から探し、細い線でつないで間を詰める。かな同士はつながりやすく、漢字はつながりにくい
- 「揺らぎを変える」で配置と字形の揺れを引き直す
- 画像（PNG）で保存できる
