# いまのことば

いまの気持ちをことばで書くと、禅語か和歌がひとつ届く小さなページ。

- 禅語 300・和歌 244 を収録（読み・意味・英訳・出典つき）
- 書いた気持ちのことばから、合いそうなものを選ぶ
- 一期一会：一度届いたことばは、同じブラウザには二度と届かない
- 気持ちに合わせて、水彩のような色がカードににじむ
- Claude 上で開いたときは、AI が気持ちを読みとって選ぶ

## ファイル

- `index.html` … ページ本体
- `kotoba.json` … ことばのデータ（`data/*.txt` から生成）
- `data/` … 元データ。1 行 1 件、`原文|読み|意味|英訳|出典|気持ちタグ`

気持ちタグ: s かなしい / l さみしい / a 不安・焦り / t つかれ / i 怒り / m 迷い / h うれしい / c おだやか / k 恋・会いたい / n なつかしい / g 前向き / r 感謝

読みや出典は確認中のものを含みます。
