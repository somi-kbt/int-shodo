# kuusho（空書）

カメラに映った手を筆にして、空中に書道をするWebアプリ。MediaPipe Hand Landmarker を使い、映像はブラウザ内だけで処理されます。

https://kuusho.vercel.app

## 書き方
- 5本の指先がだいたい外周に乗る円が丸い筆になる。指を広げると太く、すぼめると細くなる
- 速く払うとかすれ（線は途切れない）、ゆっくり動かしたり留めたりすると墨がにじむ
- グーにすると筆が上がり、線が書かれない
- 速い動きでも、手を一瞬見失った程度（0.5秒以内）なら線をつなぎ、曲線で補う
- 「書き始める」を押すと3秒数えてから15秒間書け、終わると撮影を止めて3Dで表示
- 3D表示では線がチューブ状になり、ドラッグで回転、ピンチで拡大できる。奥行きは手の見かけの大きさから推定する
- 墨の色（白墨・墨・朱・金・藍）を変えられ、3D表示のPNG保存もできる

## 3Dプリント
3D画面の「🧊 3Dプリント用に保存」で STL ファイルを保存できる。長い辺が100mmになるように大きさを合わせ、細すぎる線は半径0.9mmまで太くして印刷できるようにしている。画面で見ている奥行きのまま、台の上に立つ向きで出力する。「台座」をオンにすると（初期設定）、厚さ3mmの板を下に敷き、それぞれの線のいちばん低いところから板まで柱を立てるので、全体がひとつながりで印刷できる。

## PCで使う
- PCのWebカメラでも書ける。カメラが1台しかないときは「カメラ切替」ボタンを隠す
- スペースキーかEnterキーでも「書き始める」を押せるので、両手をカメラの前に出したまま始められる
- 3D表示はマウスのドラッグで回転、ホイールで拡大
