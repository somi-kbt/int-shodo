# kuusho（空書）

カメラに映った手を筆にして、空中に書道をするWebアプリ。MediaPipe Hand Landmarker を使い、映像はブラウザ内だけで処理されます。

https://kuusho.vercel.app

## 書き方
- 5本の指先がだいたい外周に乗る円が丸い筆になる。指を広げると太く、すぼめると細くなる
- 速く払うとかすれ（線は途切れない）、ゆっくり動かしたり留めたりすると墨がにじむ
- グーにすると筆が上がり、線が書かれない
- 速い動きでも、手を一瞬見失った程度（0.5秒以内）なら線をつなぎ、曲線で補う
- 「書き始める」を押すと3秒数えてから15秒間書け、終わると撮影を止めて3Dで表示
- 3D表示では線がチューブ状になり、ドラッグで回転、ピンチで拡大できる。奥行きは手の見かけの大きさから推定する
- 墨の色（白墨・墨・朱・金・藍）を変えられ、3D表示のPNG保存もできる

## 音
書いている線がアンビエントな音になる。高さで音程（共通のペンタトニック音階）、太さで音量、左右で定位、速さで明るさが変わり、かすれでは息のような音が混ざる。音程が変わるとガラスのような鈴が鳴り、下では低いドローンが鳴り続け、全体に長い残響がかかる。

## ふたりで書く
- 一人が「部屋をつくる」で4桁の部屋番号を作り、招待リンクを送る。もう一人はリンクを開くか、番号を入れて「部屋に入る」
- どちらかが「書き始める」を押すと、二人同時にカウントダウンが始まる
- お互いの線が両方の画面にリアルタイムで現れ、違う色・違う音色で鳴る。終わると二人の線が重なった3Dになる
- 通信は PeerJS（WebRTC）でスマホ同士を直接つなぐ。送るのは筆の位置・太さ・色だけで、映像は送らない
- 携帯回線どうしだとつながらないことがある。その場合は二人とも同じWi-Fiにつなぐ
